Page Spec Contract Format

Each page spec is an implementation contract. A future implementation prompt must reference the exact page name and the relevant detail wireframe section from page 15.

Required fieldsRoute, Page type, Purpose, Toolbar buttons, Tabs, Primary table columns, Filter columns, Detail sections, Forms, Allowed actions, Forbidden actions, Empty states, Blocked states, Navigation targets, Required data, Required status logic, Tests/checks, Open questions.

Products

Route/app/items
Page typeMaster Data Work Queue
PurposeList Shopify-backed products and Operations items with operational role, shop visibility and master-data blockers.
Toolbar buttonsSync Shopify products, New product, Export, Saved views later.
Tabs/viewsAll products, Products on shop, Needs supplier, Producible missing BOM, Operations items, Stale/Not on shop.
Primary table columnsProduct, SKU/title, Shopify status, Type, Roles, Supplier, Stock, BOM, Data quality, Next action.
Filter columnstext SKU/title, Shopify status, item type, sellable, purchasable, producible, supplier, BOM missing, on shop, stale, stock min/max.
Allowed actionsOpen product, Sync Shopify products, New Operations item, Export.
Forbidden actionsRun MRP, create PO, receive goods, put away, create shipment.
Empty statesNo products: Sync Shopify products or create Operations item.
Blocked statesMissing supplier, missing BOM, draft/archived/stale Shopify product.
Navigation targetsProduct Detail, Suppliers, BOM / Kitting.
Required dataitems, supplier_items, suppliers, boms, inventory summary, Shopify product sync status.
Required status logicProducts on shop requires active Shopify status and not stale/not archived. Operational role remains separate from shop visibility.
Tests/checksProducts on shop excludes DRAFT/ARCHIVED/stale; missing supplier/BOM filters work; no operational execution buttons.
Open questionsPublication/channel visibility if Shopify API signal is available.

Route/app/items/:itemId
Page typeMaster Data Form
PurposeMaintain operational master data for one item.

TabsMaster data, BOM summary, Shopify sync, Events later.
Detail sectionsProduct master data summary, Operational classification, Purchasing settings, QC, BOM read-only summary, Shopify status/sync state.
FormsClassification, purchasing settings, QC policy. One visible Save for the product-level form.
Allowed actionsSave master data, Cancel, Open BOM editor, Back to Products.
Forbidden actionsRun MRP, create purchase need/PO, receive, QC, putaway, shipment creation, Shopify writeback.
Blocked statesPurchasable without supplier, producible without BOM, active BOM with no components, Shopify not on shop.
Required dataitem, supplier_items, suppliers, active BOM, BOM lines, Shopify status, inventory summary.
Required status logicPlanning policy derived from purchasable/producible/sellable flags unless explicit policy exists.
Tests/checksSave all editable fields; BOM table read-only; usage section does not dominate; no operational actions.
Open questionsWhether customer-specific product restrictions are needed later.
