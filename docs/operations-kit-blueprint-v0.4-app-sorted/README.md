# Operations Kit Blueprint v0.4 — App-sorted

Diese Version ist nach App-Bereichen sortiert. Jeder Bereich hat dieselbe Struktur:

1. Entitäten
2. Prozess
3. UI

## Anzeigen

```bash
cd operations-kit-blueprint-v0.4-app-sorted
python3 -m http.server 8080
```

Dann öffnen: http://localhost:8080

## Codex-Verwendung

Für Orders: `specs/orders.md` und `orders.html` lesen.  
Für Products: `specs/products.md` und `products.html` lesen.  
Für Procurement: `specs/procurement.md` und `procurement.html` lesen.

Die alten querschnittlichen Specs sind nicht mehr die primäre Implementierungsquelle.
