Entitäten

EntitätAttribute / BedeutungRegel
ShippingOrderShipment-Kopf: shipment_number, operations_order_id, status, created/packed/shipped timestamps, shipping address snapshot.Single record für Versandarbeit.
ShippingOrderLineShipment-Zeile mit operations_order_line_id, item, quantity, picked/packed/shipped status.Direkter Link zur Nachfragezeile.
Address readinessOrder shipping address + customer name/email müssen vorhanden und nutzbar sein.Ohne Adresse kein Shipment.
Inventory readinessBestand muss für Order Line verfügbar/reserviert sein.Procurement/Receiving müssen vorher abgeschlossen sein.

Prozess

SchrittProzessregel
1. Ready/BlockedOrders mit Bestand + Adresse sind ready, sonst blocked mit genauem Grund.
2. Create ShipmentErzeugt lokalen Shipment Record und Linien. Kein Shopify Fulfillment Writeback im MVP.
3. Pack/Ship späterMark packed / Mark shipped lokal. Packing optional via Settings.
4. CompletedShipment work complete; Shopify fulfillment writeback später explizit.
